# Frontend

Обязательная часть системы. Автоматическая проверка покрывает только IPR, VLP
и Nodal; frontend оценивается на демо и live-защите.

## Что положить сюда

Код frontend и `Dockerfile`. Порт — **3000**.

Рекомендуемый минимум:

- форма ввода данных скважины;
- график IPR и VLP;
- рабочая точка;
- what-if по буферному давлению, обводнённости и шумности;
- отчёт по сценарию;
- ошибки, пустые состояния и загрузка;
- адаптивная вёрстка.

Frontend не должен содержать LLM-ключи и секреты. Все расчёты — через backend.

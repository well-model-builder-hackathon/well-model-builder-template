# AI-помощник

Обязательный модуль системы. Автоматическая проверка покрывает только IPR, VLP
и Nodal; AI-помощник оценивается на демо и live-защите.

## Что положить сюда

Промпты, описания инструментов, RAG-материалы, eval-кейсы и адаптеры провайдера.
Сам runtime обычно живёт в backend и вызывает расчётные сервисы через tool layer.

Требования:

- помощник не вызывает IPR/VLP/Nodal напрямую — только через backend/tools;
- все числа в ответе берутся из tool output;
- нехватка данных → вопросы, а не выдуманные значения;
- противоречивые единицы → уточнение или явное допущение;
- отказ сервиса → понятная ошибка, без выдуманного результата;
- tool trace сохраняется;
- LLM-ключи только на сервере и только в `.env`/secrets.

Если помощник вынесен в отдельный сервис, добавьте его в `docker-compose.yml`
под профилем `app` самостоятельно.
